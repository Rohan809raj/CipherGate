# CipherGate Formal Privacy Model & Security Audit

This document defines the formal threat model, cryptographic assumptions, and data-leakage resistance properties of the CipherGate protocol on the Midnight blockchain.

---

## 1. Threat Model & Adversary Capabilities

We assume a computationally bounded polynomial-time adversary $\mathcal{A}$ with the following capabilities:
- **Full Ledger Inspection:** $\mathcal{A}$ observes all public transactions, smart contract state transitions, blocks, and mempool broadcasts on Midnight Preprod/Mainnet.
- **Network Eavesdropping:** $\mathcal{A}$ monitors network traffic between user clients and Midnight validator RPC nodes.
- **Sybil Queries:** $\mathcal{A}$ can submit arbitrary proof tokens to the public contract to attempt correlation.

---

## 2. Privacy Guarantees

### Theorem 1 (Zero-Knowledge Inequality)
*Let $x$ be the private witness `userAge` and $T$ be the public threshold `minAgeThreshold`. The proof transcript $\pi$ reveals no information about $x$ beyond the predicate $x \ge T$.*

**Proof Sketch:** The Compact arithmetic circuit reduces the relation $x - T \ge 0$ to a satisfaction problem over SNARK polynomial commitments. Simulators without knowledge of $x$ can generate computationally indistinguishable transcripts given only the true predicate outcome.

### Theorem 2 (Unlinkability via Nullifier Entropy)
*Given two proofs $\pi_1$ and $\pi_2$ generated by the same identity secret across distinct context nonces $n_1 \ne n_2$, $\mathcal{A}$ cannot distinguish whether the proofs originate from the same user or two distinct users with probability non-negligibly greater than $\frac{1}{2}$.*
